# بازگردانی MVP تبدیل

اگر لازم شد این اپ از سایت تولید برداشته شود:

1. مطمئن شوید هیچ سند «تبدیل» Submit‌شده‌ای باقی نمانده، یا ابتدا همان سندها از UI لغو شوند.
2. از `SmartProcessERP` یک بکاپ تازه گرفته شود.
3. سپس:

```bash
bench --site SmartProcessERP uninstall-app smartprocess_erpnext_accounting
```

4. فایل override مربوط به این اپ از Compose حذف شود و سرویس‌ها با همان فایل‌های قبلی بالا بیایند.
5. پورت `8080` و سایت `SmartProcessERP` باید بدون تغییر باقی بمانند.

اگر uninstall به خاطر دادهٔ Submit‌شده مسدود شد، اول سندها را لغو کنید. GL تاریخی را دستی حذف نکنید.

بازگردانی از بکاپ native فقط وقتی لازم است که migrate یا نصب ناقص، schema را در وضعیت نامعتبر گذاشته باشد.
